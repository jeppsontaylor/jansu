I hit one environment limitation: the execution container could not resolve `github.com`, so I could not literally `git clone` or run local tests. ## What Phase 04 needs to become “done”

Phase 04 is currently reopened by audit pressure, not because it is the next normal queue item. `AUDIT-012` is still marked `blocked` because the repo lacks a stable local Kafka harness and client matrix. `MASTER_PLAN.md` also defines “done” as more than code: focused tests, broader checks or recorded blockers, attempt log, canonical phase log, manifest, `AUDIT.md`, and compatibility-ledger proof all need to be updated.  

The Phase 04 acceptance gate is precise: CI must be able to compare Jansu behavior against real Kafka for each advertised API, publish results, and feed proof into the compatibility ledger. The Phase 04 document also calls for Kafka 4.2 plus Jansu side-by-side, common workloads, Java/librdkafka first, Kafka CLI fixtures, artifacts, and reusable harnessing for later phases. 

The current advertised API surface is intentionally tiny: the broker advertises only `ApiVersionsRequest` and `MetadataRequest`, while Produce, Fetch, ListOffsets, and many other routes exist but remain unadvertised pending proof. That means Phase 04 can be finished now by proving the advertised surface against Kafka 4.2 and by creating durable infrastructure for future advertised APIs. 

The current `cg_differential.rs` is not a true differential Kafka lab: it starts a Jansu broker and uses rdkafka consumers, but it does not start Kafka or compare Jansu output against a Kafka baseline. That should stay useful as a client smoke seed, but it cannot satisfy Phase 04. 

Apache’s official Kafka 4.2 Docker documentation supports `apache/kafka:4.2.0`, and the 4.2.0 release announcement is dated February 17, 2026, which matches the repo’s Kafka 4.2 compatibility ledger baseline. ([Apache Kafka][1])

```rust
fn other_error(message: impl Into<String>) -> DynError {
    Box::new(io::Error::new(io::ErrorKind::Other, message.into()))

fn artifact_dir() -> PathBuf {
    std::env::var_os("JANSU_DIFF_ARTIFACT_DIR")
        .map(PathBuf::from)
        .unwrap_or_else(|| repo_root().join("target/differential"))

fn unix_ms() -> u128 {
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .unwrap_or_default()
        .as_millis()
}

fn write_artifact<T: Serialize>(name: &str, value: &T) -> DynResult<()> {
    let dir = artifact_dir();
    fs::create_dir_all(&dir)?;
    let path = dir.join(format!("{name}-{}.json", unix_ms()));
    fs::write(path, serde_json::to_vec_pretty(value)?)?;
    Ok(())
}

fn approved_versions_from_ledger() -> DynResult<BTreeMap<i16, VersionRange>> {
    let ledger: Ledger = serde_json::from_slice(&fs::read(LEDGER_PATH)?)?;

    Ok(ledger
        .apis
        .into_iter()
        .filter_map(|row| {
            row.approved_advertised_versions
                .map(|range| (row.api_key, range))
        })
        .collect())
}

fn api_version_map(response: &ApiVersionsResponse) -> BTreeMap<i16, VersionRange> {
    response
        .api_keys
        .as_deref()
        .unwrap_or_default()
        .iter()
        .map(|api| {
            (
                api.api_key,
                VersionRange {
                    min: api.min_version,
                    max: api.max_version,
                },
            )
        })
        .collect()
}

async fn free_port() -> DynResult<u16> {
    let listener = TcpListener::bind(SocketAddr::new(IpAddr::V4(Ipv4Addr::LOCALHOST), 0)).await?;
    Ok(listener.local_addr()?.port())
}

async fn tcp_round_trip(bootstrap: &str, request: bytes::Bytes) -> DynResult<Vec<u8>> {
    let mut stream = TcpStream::connect(bootstrap).await?;
    stream.write_all(&request).await?;

    let mut len = [0_u8; 4];
    stream.read_exact(&mut len).await?;
    let size = i32::from_be_bytes(len);
    if size < 0 {
        return Err(other_error(format!("negative Kafka frame size: {size}")));
    }

    let mut response = vec![0_u8; 4 + size as usize];
    response[..4].copy_from_slice(&len);
    stream.read_exact(&mut response[4..]).await?;
    Ok(response)
}

async fn api_versions(bootstrap: &str) -> DynResult<ApiVersionsResponse> {
    let request = Frame::request(
        Header::Request {
            api_key: ApiVersionsRequest::KEY,
            api_version: 4,
            correlation_id: 7,
            client_id: Some("jansu-phase04-differential".into()),
        },
        ApiVersionsRequest::default()
            .client_software_name(Some("jansu-phase04-differential".into()))
            .client_software_version(Some(env!("CARGO_PKG_VERSION").into()))
            .into(),
    )?;

    let response = tcp_round_trip(bootstrap, request).await?;
    let response = Frame::response_from_bytes(&response[..], ApiVersionsRequest::KEY, 4)?;
    Ok(ApiVersionsResponse::try_from(response.body)?)
}

async fn metadata(bootstrap: &str) -> DynResult<MetadataResponse> {
    let request = Frame::request(
        Header::Request {
            api_key: MetadataRequest::KEY,
            api_version: 12,
            correlation_id: 8,
            client_id: Some("jansu-phase04-differential".into()),
        },
        MetadataRequest::default()
            .topics(Some([].into()))
            .allow_auto_topic_creation(Some(false))
            .include_cluster_authorized_operations(Some(false))
            .include_topic_authorized_operations(Some(false))
            .into(),
    )?;

    let response = tcp_round_trip(bootstrap, request).await?;
    let response = Frame::response_from_bytes(&response[..], MetadataRequest::KEY, 12)?;
    Ok(MetadataResponse::try_from(response.body)?)
}

fn summarize_metadata(response: &MetadataResponse) -> MetadataSummary {
    MetadataSummary {
        broker_count: response.brokers.as_deref().unwrap_or_default().len(),
        topic_count: response.topics.as_deref().unwrap_or_default().len(),
        has_cluster_id: response.cluster_id.is_some(),
        controller_id: response.controller_id,
        throttle_time_ms: response.throttle_time_ms,
    }
}

struct KafkaGuard {
    bootstrap: String,
    compose_started: bool,
}

impl KafkaGuard {
    async fn start() -> DynResult<Self> {
        if let Ok(bootstrap) = std::env::var("JANSU_DIFF_KAFKA_BOOTSTRAP") {
            wait_for_api_versions(&bootstrap).await?;
            return Ok(Self {
                bootstrap,
                compose_started: false,
            });
        }

        let compose_file = "etc/differential/compose.kafka-4.2.yaml";
        let status = Command::new("docker")
            .current_dir(repo_root())
            .args([
                "compose",
                "-f",
                compose_file,
                "up",
                "--wait",
                "--detach",
                "kafka42",
            ])
            .status()?;

        if !status.success() {
            return Err(other_error(format!(
                "docker compose failed to start Kafka 4.2: {status}"
            )));
        }

        let port = std::env::var("JANSU_DIFF_KAFKA_PORT").unwrap_or_else(|_| "19092".into());
        let bootstrap = format!("127.0.0.1:{port}");
        wait_for_api_versions(&bootstrap).await?;

        Ok(Self {
            bootstrap,
            compose_started: true,
        })
    }

    fn bootstrap(&self) -> &str {
        &self.bootstrap
    }
}

impl Drop for KafkaGuard {
    fn drop(&mut self) {
        if self.compose_started {
            let _ = Command::new("docker")
                .current_dir(repo_root())
                .args([
                    "compose",
                    "-f",
                    "etc/differential/compose.kafka-4.2.yaml",
                    "down",
                    "--volumes",
                    "--remove-orphans",
                ])
                .status();
        }
    }
}

struct JansuGuard {
    bootstrap: String,
    task: JoinHandle<()>,
}

impl JansuGuard {
    async fn start() -> DynResult<Self> {
        let port = free_port().await?;
        let listener = Url::parse(&format!("tcp://127.0.0.1:{port}"))?;

        let broker = Broker::builder()
            .node_id(rng().random_range(1..i32::MAX))
            .cluster_id(format!("jansu-phase04-{}", Uuid::now_v7()))
            .incarnation_id(Uuid::now_v7())
            .listener(listener.clone())
            .advertised_listener(listener)
            .storage(Url::parse("slatedb://memory")?)
            .silent(true)
            .build()
            .await?;

        let bootstrap = format!("127.0.0.1:{port}");
        let task = tokio::spawn(async move {
            if let Err(error) = broker.main(Instant::now()).await {
                eprintln!("jansu differential broker exited with error: {error:?}");
            }
        });

        wait_for_api_versions(&bootstrap).await?;

        Ok(Self { bootstrap, task })
    }

    fn bootstrap(&self) -> &str {
        &self.bootstrap
    }
}

impl Drop for JansuGuard {
    fn drop(&mut self) {
        self.task.abort();
    }
}

async fn wait_for_api_versions(bootstrap: &str) -> DynResult<()> {
    let deadline = Duration::from_secs(30);

    timeout(deadline, async {
        loop {
            if api_versions(bootstrap).await.is_ok() {
                return Ok::<_, DynError>(());
            }
            sleep(Duration::from_millis(250)).await;
        }
    })
    .await
    .map_err(|_| other_error(format!("timed out waiting for {bootstrap}")))??;

    Ok(())
}

#[tokio::test]
async fn differential_api_versions_advertised_subset_of_kafka42() -> DynResult<()> {
    if !external_enabled() {
        eprintln!("skipping external differential lab; set JANSU_DIFFERENTIAL=1");
        return Ok(());
    }

    let kafka = KafkaGuard::start().await?;
    let jansu = JansuGuard::start().await?;

    let kafka_response = api_versions(kafka.bootstrap()).await?;
    let jansu_response = api_versions(jansu.bootstrap()).await?;

    let kafka_versions = api_version_map(&kafka_response);
    let jansu_versions = api_version_map(&jansu_response);
    let ledger_approved_versions = approved_versions_from_ledger()?;

    assert_eq!(
        ledger_approved_versions, jansu_versions,
        "Jansu ApiVersions must exactly match approved advertised ledger versions"
    );

    for (api_key, jansu_range) in &jansu_versions {
        let kafka_range = kafka_versions.get(api_key).ok_or_else(|| {
            other_error(format!(
                "Kafka 4.2 does not advertise Jansu-approved api_key {api_key}"
            ))
        })?;

        assert!(
            kafka_range.min <= jansu_range.min && kafka_range.max >= jansu_range.max,
            "Jansu api_key {api_key} range {jansu_range:?} must be a Kafka 4.2 subset {kafka_range:?}"
        );
    }

    write_artifact(
        "api-versions",
        &ApiVersionsArtifact {
            schema_version: 1,
            workload: "api_versions_advertised_subset_of_kafka42",
            kafka_bootstrap: kafka.bootstrap().into(),
            jansu_bootstrap: jansu.bootstrap().into(),
            kafka_versions,
            jansu_versions,
            ledger_approved_versions,
        },
    )?;

    Ok(())
}
```

```bash
#!/usr/bin/env bash
set -euo pipefail

BOOTSTRAP="${1:?usage: kafka-cli-fixtures.sh <bootstrap> <target-name> <artifact-dir>}"
TARGET="${2:?usage: kafka-cli-fixtures.sh <bootstrap> <target-name> <artifact-dir>}"
ARTIFACT_DIR="${3:-target/differential/cli}"

mkdir -p "${ARTIFACT_DIR}"

timestamp_ms() {
  python3 - <<'PY'
import time
print(int(time.time() * 1000))
PY
}

find_kafka_bin() {
  local tool="$1"

  if command -v "${tool}" >/dev/null 2>&1; then
    command -v "${tool}"
    return 0
  fi

  if command -v "${tool}.sh" >/dev/null 2>&1; then
    command -v "${tool}.sh"
    return 0
  fi

  if [[ -n "${KAFKA_HOME:-}" && -x "${KAFKA_HOME}/bin/${tool}.sh" ]]; then
    echo "${KAFKA_HOME}/bin/${tool}.sh"
    return 0
  fi

  echo "missing Kafka CLI tool: ${tool}" >&2
  return 127
}

run_fixture() {
  local name="$1"
  shift

  local out="${ARTIFACT_DIR}/${TARGET}-${name}-$(timestamp_ms).out"
  local err="${ARTIFACT_DIR}/${TARGET}-${name}-$(timestamp_ms).err"
  local meta="${ARTIFACT_DIR}/${TARGET}-${name}-$(timestamp_ms).json"

  set +e
  "$@" >"${out}" 2>"${err}"
  local status=$?
  set -e

  python3 - <<PY > "${meta}"
import json
print(json.dumps({
  "schema_version": 1,
  "target": "${TARGET}",
  "fixture": "${name}",
  "bootstrap": "${BOOTSTRAP}",
  "status": ${status},
  "stdout": "${out}",
  "stderr": "${err}",
}, indent=2))
PY

  return "${status}"
}

TOPIC="phase04-cli-${TARGET}-$(timestamp_ms)"

BROKER_API_VERSIONS="$(find_kafka_bin kafka-broker-api-versions)"
TOPICS="$(find_kafka_bin kafka-topics)"
GET_OFFSETS="$(find_kafka_bin kafka-get-offsets)"
PRODUCER="$(find_kafka_bin kafka-console-producer)"
CONSUMER="$(find_kafka_bin kafka-console-consumer)"
CONSUMER_GROUPS="$(find_kafka_bin kafka-consumer-groups)"

run_fixture broker-api-versions \
  "${BROKER_API_VERSIONS}" --bootstrap-server "${BOOTSTRAP}"

run_fixture topic-create \
  "${TOPICS}" --bootstrap-server "${BOOTSTRAP}" \
  --create --if-not-exists --topic "${TOPIC}" \
  --partitions 1 --replication-factor 1

run_fixture topic-describe \
  "${TOPICS}" --bootstrap-server "${BOOTSTRAP}" \
  --describe --topic "${TOPIC}"

printf 'k1\tv1\nk2\tv2\n' | run_fixture console-producer \
  "${PRODUCER}" --bootstrap-server "${BOOTSTRAP}" \
  --topic "${TOPIC}" \
  --property parse.key=true \
  --property key.separator=$'\t'

run_fixture get-offsets-earliest \
  "${GET_OFFSETS}" --bootstrap-server "${BOOTSTRAP}" \
  --topic "${TOPIC}" --time earliest

run_fixture get-offsets-latest \
  "${GET_OFFSETS}" --bootstrap-server "${BOOTSTRAP}" \
  --topic "${TOPIC}" --time latest

run_fixture console-consumer \
  "${CONSUMER}" --bootstrap-server "${BOOTSTRAP}" \
  --topic "${TOPIC}" \
  --from-beginning \
  --timeout-ms 10000 \
  --property print.key=true \
  --property print.offset=true \
  --property print.partition=true \
  --property print.value=true

run_fixture consumer-groups-list \
  "${CONSUMER_GROUPS}" --bootstrap-server "${BOOTSTRAP}" --list
```

````md
Phase: 04  
Audit item: AUDIT-012

The differential lab compares Jansu against a real Kafka 4.2 broker for every API
````

Phase 04 should not attempt to fix Produce, Fetch, ListOffsets, leader epochs, idempotence, or transactions. It should give those phases a stable proof machine.

After this lands:

* Phase 07 can add Produce workloads to `differential_lab.rs` and promote Produce only after the Java/librdkafka/CLI artifacts are green.
* Phase 08 can add Fetch, ListOffsets, and OffsetForLeaderEpoch workloads, including the current mixed-partition and produced-epoch failures.
* Phase 10 can replace the current Jansu-only `cg_differential.rs` posture with true Kafka-vs-Jansu group comparisons.
* Phase 16 can widen from Rust/CLI/librdkafka to Java, franz-go, Sarama, performance, and migration proof.

This makes Phase 04 complete as infrastructure, while preserving honest compatibility claims for the APIs that are still under active semantic work.
